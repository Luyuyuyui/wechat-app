# 素材清单

所有原始素材统一收放在 `materials/` 下，`assets/` 中只有经过压缩、供小程序使用的副本。

> `materials/` 与 `assets/videos/` 已在 `project.config.json` 的 `packOptions.ignore` 中声明，**不进小程序代码包**，也不影响真机调试上传。

## 目录结构

```
materials/
├── documents/          文字资料
├── images/             原始图片
├── videos/             来源视频（网络 / 媒体素材）
└── interview/          团队实地访谈原片
```

## interview/

| 文件 | 说明 |
| --- | --- |
| `IMG_8258.MOV` | 本项目团队实地访谈原片，19 分 34 秒，约 3.3 GB。**不进 git、不进代码包。** |

转码为小程序可用的副本（见 README「重新生成访谈视频」）：

```bash
ffmpeg -y -i materials/interview/IMG_8258.MOV \
  -vf "scale=-2:720:flags=lanczos" -c:v libx264 -preset medium -crf 23 \
  -c:a aac -b:a 96k -movflags +faststart -ss 00:00:02 \
  assets/videos/v11-interview.mp4
```
